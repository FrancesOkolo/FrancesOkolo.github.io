# Frances Okolo — Portfolio

A modern, responsive portfolio for Frances Okolo, a UK-based data scientist, analyst and BI developer.

## What the site highlights

- Selected Tableau and open-source projects
- Business intelligence, analytics, data modelling and research expertise
- A clear professional story with direct contact and profile links

## Run locally

This is a dependency-free static site. Open `index.html` directly or serve the folder with any static web server.

## Structure

- `index.html` — page content and metadata
- `css/main.css` — visual system and responsive layout
- `js/main.js` — navigation, reveal effects and current year
- `og.png` — social sharing preview

The site is designed to work from a GitHub Pages project path as well as from the domain root.
